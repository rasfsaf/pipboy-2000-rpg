# Pip-Boy 2000 ASCII RPG (Android / Mobile HTML Demo)

Интерактивная браузерная HTML5/CSS3/JavaScript RPG-демка в стилистике классического наручного компьютера **Pip-Boy 2000** из оригинальных Fallout 1 и Fallout 2.

Внутри монохромного ЭЛТ-дисплея с зеленым фосфором разворачивается постапокалиптическая пошаговая ролевая игра с ASCII-графикой, работающая под управлением встроенной командной строки (Custom CLI).

---

## Особенности проекта

### 1. Аутентичный корпус Pip-Boy 2000 и левый сайдбар
- **Верхний блок индикации:** Цифровой LED-счетчик даты и времени (`01 APR 2242 ☢ 0030`) и винтажная металлическая табличка Pip-Boy 2000 с маскотом Vault Boy.
- **Средний блок ламповой аппаратуры:** Отсек с винтажными светящимися радиолампами и газоразрядными индикаторами за защитной ромбовидной решеткой.
- **Нижний блок управления:** Металлическая панель с полосой предупредительной аварийной маркировки (hazard stripes), светящимися красными светодиодами (LED) и тумблерами переключения режимов:
  - `STATUS` — лист персонажа (S.P.E.C.I.A.L., навыки, радиация, уровень).
  - `MAP / GAME` — экран игры с миром в ASCII-графике и терминальным логом.
  - `INVENTORY` — инвентарь с экипировкой, оружием, медикаментами и крышками.
  - `ARCHIVES` — архивные директивы убежища Vault-Tec.
- **Межблочная проводка:** Жгуты цветных проводов (красный, синий, желтый, зеленый), соединяющие панель с монитором.

### 2. Монохромный ЭЛТ-экран (CRT Phosphor Display)
- Эффект зеленого люминофора P1 (`#33ff44`), сканлинии (scanlines), кривизна стекла монитора, кинескопные блики и легкое аналоговое мерцание.
- Информационная полоса телеметрии в реальном времени: Очки здоровья (HP), Очки действия (AP), Уровень радиации (RAD), Крышки (CAPS).

### 3. ASCII Графика & Custom CLI Engine
- **Custom CLI:** Собственный движок терминала с поддержкой ввода команд через строку `PIP-OS >` и историей команд:
  - `help` / `?` — список команд терминала.
  - `look` — осмотр текущей локации и обнаружение врагов поблизости.
  - `n`, `s`, `e`, `w` (или `move <направление>`) — перемещение по карте.
  - `attack [head|torso|legs]` — атака ближайшего противника.
  - `vats` — тактическое прицеливание V.A.T.S. по частям тела.
  - `inv` — список предметов и груза в терминале.
  - `use <предмет>` — использование стимпака, RadAway или экипировка оружия.
  - `stats` — вывод параметров S.P.E.C.I.A.L.
  - `wait` — пропуск хода и восстановление Очков Действия (AP).
  - `clear` — очистка лога консоли.
- **Сетка ASCII-мира:**
  - `@` — Игрок (Vault Dweller).
  - `#` — Бетонные стены и руины убежища.
  - `.` — Пол сектора.
  - `~` — Радиоактивная лужа (наносит радиационный урон при наступании).
  - `+` / `/` — Герметичные двери сектора (закрытые / открытые).
  - `$` — Контейнеры с припасами и патронами.
  - `>` — Лифт перехода на поверхность пустошей.
  - `r` — Радтаракан (Radroach).
  - `R` — Рейдер пустоши (Wasteland Raider).
  - `G` — Светящийся гуль (Glowing One Ghoul).
- **Туман войны (FOV):** Динамический расчет видимости вокруг персонажа.

### 4. Ролевая система в духе Fallout (S.P.E.C.I.A.L.)
- **7 характеристик:** Сила (ST), Восприятие (PE), Выносливость (EN), Харизма (CH), Интеллект (IN), Ловкость (AG), Удача (LK).
- **Производные параметры:** Очки Здоровья (HP), Очки Действия (AP), Класс Брони (AC), Порог Урона (DR), Грузоподъемность (Carry Weight), Радиационное заражение (0-1000 Rads).
- **Навыки и прокачка:** Легкое оружие (Small Guns), Рукопашный бой (Melee), Первая помощь (First Aid), Взлом (Lockpick). Опыт (XP) начисляется за победу над монстрами и исследование; при повышении уровня даются очки распределения навыков.
- **Пошаговый бой и V.A.T.S.:**
  - Расчет шанса попадания зависит от навыка, ловкости, восприятия и дистанции.
  - Прицельные выстрелы в Голову (высокий крит и 2.2x урон при пониженной меткости), Торс (стабильное попадание) и Ноги.
  - ИИ противников преследует игрока и наносит контратаки.

### 5. Адаптивность для Android и мобильных устройств
- Встроенный виртуальный D-Pad (кнопки движения и ожидания).
- Быстрые сенсорные кнопки действий: `⚔ ATK`, `🎯 VATS`, `💉 STIM`, `🎒 INV`.
- Адаптивная верстка, комфортно отображающаяся как на смартфонах/планшетах, так и на десктопных экранах.

### 6. Встроенный Web Audio API синтезатор
- Механические щелчки кнопок и переключателей Pip-Boy.
- Реалистичный треск счетчика Гейгера в радиоактивных зонах.
- Фоновый гул кинескопа (CRT 60Hz hum).
- Звуки выстрелов, ударов и мелодия повышения уровня (без внешних тяжелых mp3-файлов).

## Как поделиться и открыть на телефоне

### 1. Онлайн-ссылка (GitHub Pages)
Игра развернута в сети и доступна с любого смартфона (Android, iPhone) без установки:
**https://rasfsaf.github.io/pipboy-2000-rpg/**

### 2. QR-код прямо в игре
В правом верхнем углу интерфейса Pip-Boy нажмите кнопку **«📱 ДЛЯ ТЕЛЕФОНА / QR»**. Откроется модальное окно с QR-кодом, который можно отсканировать камерой любого телефона, чтобы моментально запустить демку.

## Локальный запуск проекта

Так как проект реализован на нативном стеке (HTML5, Vanilla JS, CSS3), ему не требуются сторонние сборщики:

1. Откройте файл `index.html` в любом браузере на ПК или мобильном устройстве.
2. Для тестирования адаптивного режима в браузере нажмите `F12` или `Ctrl+Shift+M` (Device Mode в Chrome/Edge/Firefox).
3. Для локального запуска по Wi-Fi в одной сети можно запустить команду:
   ```bash
   npx serve .
   ```
   и открыть отобразившийся локальный IP-адрес на смартфоне.
